# KT5 — Практикум по алгоритмам

Решения шести задач на Java.

## Задачи

1. **Task1** — генерация правильных скобочных последовательностей (backtracking).
2. **Task2** — динамический словарь и количество слов с заданным префиксом (trie).
3. **Task3** — два числа, встречающиеся по одному разу (XOR).
4. **Task4** — подсчёт расстановок ферзей с запрещёнными клетками (backtracking и битовые маски).
5. **Task5** — динамический словарь и k-е слово по префиксу (trie).
6. **Task6** — максимальный XOR непрерывного фрагмента (префиксный XOR и бинарный trie).

## Запуск

Из корня проекта:

```bash
javac src/Task1.java
java -cp src Task1
```

Для других задач замени `Task1` на `Task2`, `Task3`, `Task4`, `Task5` или `Task6`.

## Сложность

- Task1: O(Catalan(n) × n), с учётом формирования вывода.
- Task2: O(L) на ADD, REMOVE и COUNT, где L — длина слова/префикса.
- Task3: O(n) времени и O(n) памяти.
- Task4: перебор допустимых расстановок; n ≤ 14.
- Task5: O(26 × L) на KTH, где L — длина пути в trie.
- Task6: O(30n) времени и O(30n) памяти.
